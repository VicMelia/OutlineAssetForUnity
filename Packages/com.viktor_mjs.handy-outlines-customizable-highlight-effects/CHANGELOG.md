#Changelog
These are the changes made to the Handy Outlines - Customizable Highlight Effects Package, realeaded by Victor Melia Vilar (Vik_mjs) in 2026.

## [1.0.0] - 2026-01-30
### Added
- Initial release of the Handy Outlines - Customizable Highlight Effects Package.
- Customizable outline effects for GameObjects in Unity.
- User-friendly interface for adjusting outline properties such as color, thickness, and style.
- Support for multiple outline styles including solid, dashed, and glowing effects.
- Compatibility with Unity's Universal Render Pipeline (URP).
- Performance optimizations to ensure smooth rendering of outlines.
- Documentation to help users get started quickly.
- Sample textures and materials to demonstrate outline effects.
- Support for both 2D and 3D GameObjects.
